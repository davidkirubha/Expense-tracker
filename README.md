# Expense Tracker

A simple and responsive Expense Tracker web application built using HTML, CSS, and JavaScript. It helps users manage their income and expenses and track their available balance.

## 🚀 Live Demo
https://expense-tracker-phi-plum-77.vercel.app

## ✨ Features

- Add income and expense transactions
- View total income
- View total expenses
- Automatically calculate remaining balance
- Select transaction categories
- View transaction history
- Delete transactions
- Store transaction data using Local Storage
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## ⚙️ How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/davidkirubha/Expense-tracker.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
